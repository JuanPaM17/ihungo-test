# IA 2 — Co-creación guiada

Este directorio contiene los entregables del reto IA 2:

- `RESPUESTAS.md`: respuestas a las 15 preguntas.
- `specs/requirements.md`: historias de usuario y criterios verificables.
- `specs/design.md`: diseño y alternativas descartadas.
- `specs/plan.md`: unidades de trabajo dimensionadas y trazadas.
- `specs/rules.md`: reglas entregadas al asistente.
- `specs/bitacora.md`: decisiones, correcciones y rechazos realizados durante la co-creación.

Funcionalidad seleccionada para el ejercicio práctico: **carga masiva de asociados** del Backend 4.
